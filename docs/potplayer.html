功能

熟悉的 Companion 操作，完整交給 PotPlayer

01

媒體檔案按鈕

Bridge 掃描指定資料夾，模組為每個檔案自動建立 Preset。按鈕顯示檔名，拖入頁面就能播放。

02

即時播放狀態

播放、暫停、時間、剩餘秒數、音量、靜音與倍速每 500 ms 更新，可直接驅動 Feedback 和 Trigger。

03

多螢幕輸出

一個 Action 把 PotPlayer 移到指定螢幕並切換全螢幕，適合展演、導播與多顯示器播放。

04

播放清單與循環

上一個、下一個、加入、清除、隨機播放，以及不循環、單曲循環、自動下一首、清單循環、隨機播放和 AB 循環都能放上控制面板。

05

畫面與視窗

控制旋轉、常用比例、亮度、對比、飽和度、色相、置頂、最小化與播放清單視窗。

06

安全的區網連線

每套 Bridge 自動產生隨機配對 Token。Companion 經過認證後才能控制，適合可信任 LAN 或 VPN。

運作方式

模組負責按鈕，Bridge 負責 Windows

Companion 可以在同一台電腦、另一台電腦或伺服器上執行。只有小型 Bridge 需要留在播放用 Windows。

安裝

三個步驟開始控制

1

執行 Bridge

依 Windows CPU 下載 ARM64 或 x64 版，放在可寫入的資料夾並執行。設定檔位於使用者的 Local AppData。

2

匯入模組

在 Companion 的 Modules 頁面匯入 potplayer-remote-0.3.0.tgz，再新增 PotPlayer Remote connection。

3

配對與選片

輸入 Windows IP、Port 19191 和 Bridge 顯示的 Token。設定媒體資料夾後，按「更新媒體檔案清單」。
