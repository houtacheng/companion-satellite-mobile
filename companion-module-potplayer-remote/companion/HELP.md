# PotPlayer Remote

此模組透過 Windows 上的 **PotPlayer Companion Bridge** 控制 PotPlayer，並取得即時播放狀態。

## 連線前準備

1. 在播放用 Windows 電腦啟動 PotPlayer Companion Bridge。
2. 第一次啟動時，Bridge 會建立 `bridge-settings.json` 及隨機配對金鑰。
3. Windows 防火牆只允許私人網路連入 TCP `19191`。
4. 在 Companion 輸入 Windows 電腦 IP、連接埠 `19191` 與配對金鑰。

請只在可信任的區域網路或 VPN 中使用，不要把連接埠直接公開到網際網路。

## 支援功能

- 播放、暫停、切換、停止
- 精確跳秒、指定時間與百分比跳轉
- 音量、靜音、倍速
- 上一個／下一個
- 全螢幕、視窗置頂
- 單格前進／後退、截圖、關閉播放器
- 字幕顯示，以及不循環、單曲循環、自動下一首、清單循環與隨機播放模式
- Windows 路徑／網址開啟與媒體資料夾選單
- 每個媒體檔案自動產生 Preset，按鈕直接顯示檔名
- 選片後從頭播放、指定螢幕全螢幕、播放完畢自動關閉
- 播放清單加入／清除／隨機播放與 AB 循環
- 影片旋轉、畫面比例、亮度／對比／飽和度／色相相對調整
- 視窗最小化／還原及播放清單視窗切換
- 播放時間、總長度、倒數、音量、靜音與播放狀態變數

## 媒體檔案按鈕

在 Bridge 設定媒體資料夾後，執行「更新媒體檔案清單」。模組會在 Presets 的
「媒體檔案（按鈕顯示檔名）」分類中，為每個檔案建立一個可直接拖入頁面的按鈕；操作方式與
IINA Remote 相同。

目前全螢幕、置頂與字幕回饋反映由 Companion Bridge 發出的操作；若直接在 PotPlayer 介面更改，狀態可能要等後續版本重新同步。
